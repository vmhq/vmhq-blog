# CLAUDE.md

## Project Overview

`vmhq-blog` is a minimalist personal blog built with:
- **Bun**
- **React 19**
- **Vite 8**
- **TypeScript 5.9**
- **Tailwind CSS 4**
- **Vitest 4**

Content is written in **Spanish**. Code, config, and technical docs stay in **English**.

## Working Rules

- Use **Bun** for package management and scripts.
- Do not reintroduce `npm`, `package-lock.json`, or `autoprefixer`.
- Keep the blog visually minimal and readable.
- Be conservative with visual changes: preserve typography, spacing, and dark-mode readability.
- Prefer small, surgical edits over broad refactors.

## Commands

```bash
# Install
bun install

# Dev server
bun run dev

# Tests
bun run test

# Build
bun run build

# Lint
bun run lint
```

## Content Model

Posts are Markdown files under:

```bash
posts/YYYY/mes/*.md
```

Each post uses frontmatter:

```md
---
title: Título del post
slug: titulo-del-post
date: 2026-03-13
time: 21:35:00   # optional, recommended for ordering posts from the same day
---
```

Do not move posts back into hardcoded arrays or inline TS content.

## Build / Feed Notes

- RSS and sitemap are generated by `scripts/generate-feeds.ts`
- `prebuild` runs automatically before `bun run build`
- If content changes, expect `public/rss.xml` and `public/sitemap.xml` to change too

## Styling Notes

- Tailwind 4 is enabled through:
  - `@import "tailwindcss";`
  - `@config "../tailwind.config.ts";`
- PostCSS uses `@tailwindcss/postcss`
- Theme tokens are CSS variables in `src/index.css`
- Dark mode uses the `dark` class and must remain readable

## Vercel

The project is configured for Vercel with:
- `bun install`
- `bun run build`
- output directory `dist`
- SPA rewrite to `index.html`

Vercel Analytics and Speed Insights are already installed.

## Before Finishing Work

Always run, when relevant:

```bash
bun run test
bun run build
```

If you touch content or feed generation, include updated:
- `public/rss.xml`
- `public/sitemap.xml`
